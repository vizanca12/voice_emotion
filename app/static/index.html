Scores are on RAVDESS actors the models never heard (actors 21–24 held out entirely; actors 17–20 used only to pick the stopping epoch). The headline metric is UAR — unweighted average recall — because RAVDESS contains half as many neutral clips as any other emotion, so plain accuracy flatters a model that ignores the rare class. Splitting clips at random instead of by speaker would let the network recognise the actor rather than the emotion, and inflate every number here.
